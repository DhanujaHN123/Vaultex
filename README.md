\# VaultX



\### Vault Built on Trust



VaultX is a digital banking mobile application prototype built using React Native and Expo, with a Node.js, Express, and MongoDB backend.



The application provides a secure and user-friendly interface for managing accounts, viewing balances, sending and receiving money, paying bills, and viewing transaction history.



\## Features



\- User registration and login

\- OTP verification flow

\- 4-digit PIN authentication

\- Account management

\- Dashboard with balance information

\- Send money

\- Receive money

\- Transaction history

\- Bill payments

\- Cards

\- Insurance

\- Investments

\- Loans

\- Profile management

\- Help and support

\- Backend API integration

\- Local MongoDB database

\- Authentication and validation middleware

\- Rate limiting
